# Dazzle Automotive

A bilingual Arabic and English showroom website for DAZZLE Automotive in Riyadh.

This is a static preview. Vehicle availability, the 360° tour, appointment delivery, and official quiz result recording are not yet connected. The quiz displays provisional results on the visitor's device only.

The car logo images used in the quiz are from [car-logos-dataset](https://github.com/filippofilip95/car-logos-dataset). Other showroom photographs and videos were supplied for this site.
